# Decision records

One file per consequential choice, named by the date it was recorded. Each states
the problem, the course taken, and the alternatives that were available, so a
later contributor can tell a deliberate choice from an accident.

Every record here was reconstructed on 2026-08-20 from the code as it stands.
This repository has no commit history, so the original discussion is not
recoverable; where a rationale is a reading of the code rather than a known
reason, the record says so. A record marked Accepted means the code implements
it, not that anyone has revisited it.

This index is maintained by hand.
