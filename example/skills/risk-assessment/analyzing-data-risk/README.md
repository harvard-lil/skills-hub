# Analyzing Data Risk

This skill walks you through a risk assessment of one public dataset using
America's Data Index risk rubric. The result is a rating for each rubric
dimension, a one-sentence justification for each, and a machine-readable
summary you can keep alongside the dataset.

## Before you start

Have the dataset's name and publishing agency ready. The assessment is more
useful if you also know how often the dataset is updated and who depends on it;
the agent will ask for these if you don't say.

## Starting a conversation

> Assess the risk to the EPA Toxics Release Inventory.

The agent asks follow-up questions before rating anything. Answer what you
know and say so when you don't; a rating marked as uncertain is more useful
than one built on a guess.

## What you get back

- A low / medium / high rating for each rubric dimension, with its evidence
- An overall assessment
- The same results as structured data

## Limits

The assessment reflects what you and the agent can find in the conversation.
It is not a prediction, and it does not monitor the dataset afterwards.
