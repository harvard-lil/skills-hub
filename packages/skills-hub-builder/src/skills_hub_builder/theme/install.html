Install Everything

One install adds all {{ suite_bundle.skill_count }} skills, each with its own description, so your agent picks the right one for each request. Use this or the packs below, not both: installing the same skill twice gives your agent two copies to choose between.

Claude

On claude.ai or in the Claude desktop app, open Customize → Plugins, choose Add → Upload plugin, and upload this file. It also appears in Cowork, and in Claude Code when you sign in with the same account.

Download {{ suite_bundle.display_name }} (.zip)

Claude Code

In a session, this adds the site’s plugin catalog and opens the bundle’s install screen (Claude Code 2.1.275 or later). Later, /plugin marketplace update {{ suite_bundle.marketplace }} brings in new versions. 

/plugin install {{ suite_bundle.name }} --marketplace {{ suite_bundle.url(suite_bundle.marketplace_path) }}

Other agents

The open-source skills installer (Node.js 22.20 or later) copies every skill into the folders that Codex, Cursor, Gemini CLI, GitHub Copilot, and other agents read, and asks which agents you use. Add -g to install for your user rather than the current project; npx skills update brings in new versions. 

npx skills add {{ suite_bundle.base_url or './' }} --skill '*'

Without Node.js, download the .zip and copy the folders under skills/ into your agent’s skills folder.

Install a Skill Pack

Each group on the skills page offers a pack — one download that bundles the group’s skills and routes your requests to the right one automatically. Individual skills are available the same way if you only want one.

  1. Download the .skill file for the pack or skill you want.
  2. Add it to your agent. In Claude, open Customize → Skills and upload the file. In Claude Code, unzip it into your .claude/skills/ folder. Other agents that support the open Agent Skills standard have an equivalent place for skills — check your agent’s documentation.
  3. Ask for the task in plain language. The skill activates on its own when your request matches what it does.

A .skill file is just a zip of readable instructions — you can open it and read exactly what your agent will be told to do. If your agent has no skills support at all, opening the zip and pasting SKILL.md into your chat works too.
